# Проверка ноябрьских акций

Изменения выполнены только локально. Публикация не выполнялась.

Для оформления использованы правила CLAUDE.md и CLAUDE_FULL.md, существующие компоненты карточек и баннеров, css/tokens.css и css/pages/promos.css, css/pages/promo-offer.css. Файл design-system-clinic.json изучен как более ранняя версия: его палитра и шрифт отличаются от действующих страниц, поэтому текущие токены сохранены.

## Проверки

Штатный design-check.mjs запущен для 11 страниц: главной, услуг, списка акций и восьми отдельных предложений. Ширины: 375, 430, 768, 820, 1024, 1100, 1200 и 1440 px. Выполнено 88 проверок страниц. Ошибок: 0. Предупреждений: 200 — преимущественно маленькие цели нажатия точек общих каруселей, а также эвристические замечания к сетке и свободному месту общих секций. Эти предупреждения не означают, что все аспекты доступности проверены.

Скрипт обновлён для текущих URL, нескольких страниц за один запуск и проверки HTTP-ошибок. При измерении раскрываются элементы с data-rr, чтобы анимации не скрывали проверяемый текст. HTTP 304 корректно принимается как ответ из кеша.

Скриншоты сделаны через screenshot.mjs. Первый снимок показал, что скрипт захватывает начало анимации. Подготовка снимка исправлена: раскрываются элементы появления, загружаются ленивые изображения, ожидается загрузка шрифтов. Эти изменения действуют только в тестовом браузере. Исправлена нумерация PNG и добавлен необязательный параметр ширины.

Повторные снимки списка акций при 1440 и 375 px визуально проверены. Новые предложения используют существующий стиль карточек. Снимки находятся в temporary screenshots/screenshot-55-november-desktop-review.png и temporary screenshots/screenshot-55-november-mobile-review.png.

## Повторный запуск

При работающем локальном сервере:

```sh
BASE_URL=http://127.0.0.1:3001 node design-check.mjs --page=index,services,promos,promos/first-visit,promos/cashback,promos/laser-combo,promos/cleansing-peeling,promos/biorevit-photo,/rf-exso-foto/,/kurs-pilingov/,/lazernaya-epilyacziya-dlya-novyh-paczientov/
node screenshot.mjs http://127.0.0.1:3001/category/akcii/ november-desktop
node screenshot.mjs http://127.0.0.1:3001/category/akcii/ november-mobile 375
```
